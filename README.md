# Nanopublications: a decentralized common for research knowledge

Slides for the RDF & Linked Data seminar at the University of Geneva, 29 September 2026.

The deck is a [dokieli](https://dokie.li/) slideshow: `index.html` is a single HTML+RDFa document in which each slide is a `bibo:Slide`. Open it in a browser to present; append a slide id to jump straight into full-screen mode, e.g. `index.html#cover`.

Images used by the slides are in `media/`.
